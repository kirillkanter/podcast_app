# Сервер синхронизации Basic Caster

[oPodSync](https://github.com/kd2org/opodsync) — открытый сервер синхронизации
подкастов с протоколом gPodder (лицензия AGPL-3.0, см. LICENSE), без изменений
кода. Своё здесь только `server/data/config.local.php` и `server/data/.htaccess`.

Версия: коммит 40ae381 (11.09.2026) из github.com/kd2org/opodsync.

Требования: PHP 7.4+ (лучше 8.x) с SQLite3, Apache 2.4 с поддержкой .htaccess.

## Установка на хостинг

1. Создать поддомен `sync.bcaster.ru` и включить для него SSL-сертификат.
2. Загрузить содержимое папки `server/` (вместе со скрытыми файлами `.htaccess`)
   в корневую папку поддомена.
3. Папке `data/` дать права на запись для PHP (обычно уже есть).
4. Открыть https://sync.bcaster.ru — должна открыться страница входа
   с кнопкой регистрации.

Данные пользователей лежат в `data/data.sqlite` — его стоит регулярно
сохранять (резервная копия).
