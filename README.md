<h1 align="center">Basic Caster</h1>

<p align="center">
  Подкасты, аудиокниги и электронные книги в одном приложении.<br>
  Android и Windows, синхронизация между устройствами.
</p>

<p align="center">

---

Basic Caster заменяет три приложения: подкаст-плеер, плеер для своих аудиокниг
и читалку. Где бы вы ни остановились — в выпуске, в главе аудиокниги или на
странице книги, — на другом устройстве можно продолжить с того же места.

## Подкасты

- Поиск по каталогу Apple Podcasts и чарты по жанрам и странам; любой подкаст —
  по ссылке на RSS или на страницу в Apple Podcasts.
- Новые выпуски, очередь, архив прослушанного, свайпы в списке эпизодов.
- Загрузки для прослушивания без сети: автозагрузка новых выпусков, только по
  Wi‑Fi, лимит места, удаление прослушанного.
- Скорость для каждого подкаста, настраиваемая перемотка, таймер сна.
- Главы и таймкоды из описания: нажатие на время перематывает к нему.
- Импорт и экспорт подписок в OPML.
- Синхронизация подписок, места в выпусках, очереди и архива по протоколу
  gPodder — со своим сервером или с любым совместимым.

## Аудиокниги

- Папка с MP3, M4B, M4A, OGG, OPUS или FLAC становится книгой: с обложкой
  и главами из тегов или по файлам.
- Новые книги в выбранных папках появляются сами.
- Своя скорость у каждой книги, отмотка назад после паузы, таймер сна до конца
  главы, закладки.
- Место в книге синхронизируется между устройствами.

## Книги

- EPUB, FB2, FBZ и TXT: постраничная вёрстка, оглавление, сноски, картинки,
  поиск по тексту.
- Шрифты PT Serif, Golos и OpenDyslexic, светлая и тёмная бумага и сепия, поля,
  интервалы, выравнивание, анимация перелистывания, две колонки в альбомной
  ориентации, режим во весь экран.
- Перевод слова и фразы и значение из Викисловаря одним касанием.
- Выделения цветом с заметками, закладки, листание кнопками громкости.
- Статистика чтения по дням.
- Сами книги, место, заметки, закладки, статистика и обложки
  синхронизируются между устройствами.

## Windows

Полноценное приложение, а не веб-страница: подписки в боковой панели, книги
разворотом в две колонки, кнопки управления на панели задач, горячие клавиши,
сворачивание в трей и автозапуск.

## Оформление

Светлая и тёмная тема, восемь акцентных цветов на выбор.

## Синхронизация

Подписки и место в выпусках синхронизируются по открытому протоколу gPodder.
Книги, очередь, архив, заметки и статистика — через расширение сервера
из папки [`sync-server`](sync-server). Сервер основан на
[oPodSync](https://github.com/kd2org/opodsync) и работает на обычном хостинге
с PHP и SQLite; установка и обновление описаны в
[sync-server/README.md](sync-server/README.md).

## Сборка

Каждое изменение проверяется и собирается в GitHub Actions: тесты, APK для
Android и программа для Windows. Готовые файлы — во вкладке Actions,
в разделе Artifacts нужной сборки.

### Локально (Windows, PowerShell)

Нужны Flutter (stable), Android Studio с Android SDK и Visual Studio
с компонентом «Desktop development with C++». Проверка окружения —
`flutter doctor`.

```powershell
# Платформенные папки android/ и windows/ (существующие файлы не перезаписываются)
flutter create --platforms=android,windows --project-name podcast_app .
dart run tool/patch_platforms.dart

flutter pub get

# Код базы данных: повторять после каждого изменения lib/data/db/tables.dart
dart run build_runner build --delete-conflicting-outputs

flutter test
flutter run -d windows
```

Полная последовательность шагов для обеих платформ —
в [.github/workflows/build.yml](.github/workflows/build.yml).

## Устройство проекта

```
lib/
  feed/        загрузка и разбор фидов: RSS 2.0, iTunes, Podcasting 2.0, кодировки, даты
  catalog/     поиск и чарты Apple Podcasts с кэшем на диске
  data/        база данных (drift + SQLite), OPML, обновление подписок
  player/      воспроизведение подкастов и аудиокниг (just_audio, audio_service)
  download/    очередь загрузок
  books/       аудиокниги и текстовые книги: папки, теги, EPUB/FB2/TXT, перевод
  sync/        синхронизация: gPodder, книги, заметки, статистика
  platform/    Android и Windows: уведомления, фоновая работа, окно, трей
  ui/          экраны приложения
sync-server/   сервер синхронизации (oPodSync и расширения)
test/          тесты, в том числе синхронизации с настоящим сервером
tool/          сборка: платформенные файлы, иконки, вспомогательные скрипты
```

Несколько решений, от которых зависит поведение:

- **Ключ эпизода** — `g:<guid>`, без guid — `u:<адрес файла>`. От него зависит,
  сохранится ли позиция при обновлении фида и не появится ли дубль.
- **Эпизоды, пропавшие из фида, не удаляются**: многие фиды отдают только
  последние выпуски, а у старых может быть позиция или загрузка.
- **Неизменившийся фид не разбирается заново**: приложение помнит отпечаток
  содержимого и пропускает разбор и запись в базу.
- **Синхронизируемые записи** хранят время изменения и пометку «не отправлено»;
  конфликт решается в пользу более позднего изменения, удаление мягкое.

## Ограничения

- Фиды Atom и RSS 1.0 (RDF) не поддерживаются.
- Из однобайтовых кодировок поддержаны windows-1251, windows-1252
  и ISO-8859-1; KOI8-R пока нет.
