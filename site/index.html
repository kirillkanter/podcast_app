Аудиокниги из папки

Скачали книгу архивом MP3 — распакуйте и укажите папку. Приложение само соберёт книгу: обложка, главы из тегов или по файлам. Новые книги в этой папке появятся сами.

  • помнит место и скорость в каждой книге;
  • после паузы отматывает на несколько секунд назад;
  • таймер сна до конца главы;
  • закладки, управление из шторки и кнопками наушников.

MP3, M4B, M4A, OGG, OPUS, FLAC

Подкасты

Поиск по каталогу Apple Podcasts — там почти все подкасты, русские тоже. Чарты по жанрам, добавление по ссылке на RSS.

Новые выпуски скачиваются сами, можно только по Wi‑Fi, и играют без интернета. Подписки из другого приложения переносятся файлом OPML.

Читалка с переводом

EPUB, FB2 и TXT. Удержите палец на незнакомом слове — появится перевод слова, перевод всей фразы и значение из Викисловаря. Лучше всего работает с английским.

Выделения цветом, заметки, полки для книг, тёмная тема и сепия. Страницы листаются кнопками громкости.

Одна библиотека

Подкасты, аудиокниги и текстовые книги лежат рядом. Можно разложить книги по своим полкам и посмотреть, сколько вы слушали и читали за неделю.

Без аккаунта

Библиотека, места в книгах и заметки хранятся только на телефоне.

Легко переехать

Подписки из другого плеера переносятся файлом OPML, для аудиокниг достаточно указать ту же папку.

Работает без сети

Скачанные выпуски и аудиокниги играют в самолёте и в метро.
